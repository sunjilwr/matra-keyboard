### ⌨️ Matra (মাত্রা) v1.0.0 - Native Cross-Platform Bangla & English Keyboard

Written in 100% Pure Rust with zero external crates. Ultra-fast, bloatware-free, and conflict-free for Windows, Linux, and macOS.

#### ✨ Key Features:
- **Zero Bloat & Blazing Fast**: Pure Rust native implementation. Minimal memory footprint with zero background CPU overhead.
- **Sleek Floating OSD Badge**: Displays a modern, non-intrusive `BN` / `EN` pill near your typing cursor.
- **Per-Window Independent State**: Automatically remembers keyboard mode per application (e.g. Word = BN, VS Code = EN).
- **Accurate Bangla Engine**: Perfect handling of 'ফ্রেন্ডলি', 'কর্ম', 'সেই', CapsLock protection, conjuncts (যুক্তবর্ণ), and fola (ফলা).
- **Silent Operation & Tray**: Seamless system tray integration, auto-start, and conflict-free shortcuts.
- **Cross-Platform Installers**: Native installers and packages available for Windows, Linux (Ubuntu/Debian/Mint/Generic), and macOS.
